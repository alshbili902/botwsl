# بوت وصل للخدمات الإلكترونية (WASL) – مولّد الإعلانات الرسمي على تيليجرام

بوت تيليجرام احترافي خاص ومصمم خصيصاً لعلامة **وصل للخدمات الإلكترونية – WASL**، يقوم باستقبال نص الإعلان أو الخبر باللغة العربية عبر تيليجرام، ووضعه تلقائياً داخل القالب الرسمي المعتمد للشركة مع إضافة **اليوم والتاريخ الميلادي والتاريخ الهجري (تقويم أم القرى) والوقت الحالي بتوقيت الرياض**، ثم إرسال صورة **PNG** عالية الجودة جاهزة فوراً للنشر في حالة واتساب ومنصات التواصل الاجتماعي.

---

## أبرز المميزات

- **الحفاظ الصارم على القالب الرسمي (`571×1024` بكسل):** يستخدم القالب الأصلي `assets/templates/wasl-template.jpeg` دون أي قص أو تغيير أبعاد أو تعديل على الشعار أو الجرس الذهبي أو المكبر أو الفوتر الثابت (`0556805220`)، مع تحقق تلقائي عبر بصمة `SHA-256`.
- **طباعة عربية احترافية بخط Tajawal المحلي:** يعتمد على محرك عرض HTML/CSS عبر **Playwright Chromium** لدعم تشكيل الحروف العربية المتصلة وعلامات الترقيم والنصوص المختلطة (عربي + إنجليزي + أرقام) من اليمين إلى اليسار (`RTL`)، مع دمج الطبقات الشفافة عبر مكتبة **Sharp**.
- **ضبط تلقائي ذكي لحجم الخط:** يكبّر الخط للإعلانات القصيرة ويصغّره تدريجياً للإعلانات الطويلة والفقرات المتعددة مع رفض النصوص الفائضة برسالة واضحة بدلاً من إنتاج صورة غير مقروءة.
- **التاريخ والوقت بتوقيت المملكة (`Asia/Riyadh`):** يحتسب اسم اليوم بالعربية، والتاريخ الميلادي (`Luxon`)، والتاريخ الهجري وفق تقويم أم القرى (`@umalqura/core`)، والوقت بنظام 12 ساعة (`صباحاً` / `مساءً`) لحظة إنشاء كل صورة.
- **حماية وخصوصية تامة:** لا يعمل البوت إلا مع معرفات تيليجرام المصرح لها في `AUTHORIZED_USER_IDS` عبر متغيرات البيئة.
- **جاهز للإنتاج على AWS Ubuntu مع PM2:** يعمل بنظام **Long Polling** دون الحاجة إلى نطاق (Domain) أو شهادة SSL أو Docker.

## المتطلبات الأساسية

- **نظام التشغيل:** Ubuntu 22.04 LTS أو 24.04 LTS (لخادم AWS EC2) أو Windows / macOS للتطوير المحلي.
- **Node.js:** الإصدار `20.x LTS` أو أحدث (`22.x` موصى به).
- **ذاكرة الخادم الموصى بها على AWS:** `t3.small` (2GB RAM) أو `t3.micro` مع تفعيل ملف Swap بحجم 1GB–2GB لتشغيل متصفح Chromium بالخلفية بسلاسة.

---

## 1. إعداد البوت عبر BotFather واستخراج التوكن

1. افتح تطبيق تيليجرام وابحث عن الحساب الرسمي الموثق: `@BotFather`.
2. أرسل الأمر `/newbot`.
3. اختر اسماً ظاهراً للبوت، مثلاً: `وصل للخدمات الإلكترونية – الإعلانات`.
4. اختر معرفاً فريداً ينتهي بـ `bot`، مثلاً: `wasl_announce_bot`.
5. سيظهر لك رمز التوكن (`HTTP API Token`) بالشكل التالي:
   `1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
6. احتفظ بهذا الرمز في مكان آمن لوضعه في حقل `BOT_TOKEN` داخل ملف `.env`، ولا تشاركه نهائياً.

---

## 2. معرفة معرف المستخدم في تيليجرام (`AUTHORIZED_USER_IDS`)

البوت خاص ولا يستجيب إلا لمعرفات تيليجرام الرقمية المدرجة في الإعدادات:

1. ابحث في تيليجرام عن بوت مثل `@userinfobot` أو `@GetMyIDBot`.
2. اضغط `Start`، وسيظهر لك رقم المعرف الخاص بك (`Id`) مثل: `987654321`.
3. ضع هذا الرقم في متغير `AUTHORIZED_USER_IDS` داخل ملف `.env`.
4. إذا أردت التصريح لأكثر من حساب (مثلاً حسابك الشخصي وحساب شريكك)، افصل بين الأرقام بفاصلة `,` بدون مسافات:
   ```env
   AUTHORIZED_USER_IDS=987654321,123456789
   ```

---

## 3. إعداد متغيرات البيئة (`.env`)

انسخ ملف النموذج `.env.example` إلى ملف جديد باسم `.env`:

```bash
cp .env.example .env
```

ثم عدّل القيم داخل `.env`:

```env
BOT_TOKEN=1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
AUTHORIZED_USER_IDS=987654321
TIMEZONE=Asia/Riyadh
LOCALE=ar-SA
MAX_ANNOUNCEMENT_LENGTH=1200
```

> **تنبيه أمني:** ملف `.env` مضاف مسبقاً إلى `.gitignore` حتى لا يتم رفعه بالخطأ إلى GitHub.

## 4. التثبيت والتشغيل المحلي (Local Development)

```bash

# 2. تثبيت متصفح Chromium الخاص بـ Playwright

# 4. تشغيل الاختبارات الشاملة

```

## 5. النشر الكامل على خادم AWS Ubuntu باستخدام PM2

اتصل بخادم Ubuntu على AWS عبر SSH ثم نفّذ الخطوات التالية بالترتيب:

### الخطوة 1: تحديث النظام وتثبيت Node.js 22 LTS و Git

```bash
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install -y curl git build-essential

# تثبيت Node.js 22 LTS عبر NodeSource
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# التحقق من الإصدارات
node -v
npm -v
```

*(اختياري ولكن موصى به على خوادم `t2.micro` / `t3.micro` ذات الذاكرة 1GB: إضافة مساحة Swap بحجم 2GB لضمان استقرار Chromium):*

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### الخطوة 2: جلب المشروع وتثبيت الاعتماديات ومتصفح Chromium

```bash
cd ~
git clone <YOUR_PRIVATE_REPO_URL> wasl-telegram-bot
cd wasl-telegram-bot

# تثبيت حزم Node.js
npm install --omit=dev

# تثبيت Chromium مع جميع مكتبات النظام المطلوبة على Ubuntu تلقائياً
npx playwright install --with-deps chromium
```

### الخطوة 3: إعداد ملف البيئة `.env` واختبار الجاهزية

```bash
cp .env.example .env
nano .env
```

أدخل `BOT_TOKEN` و `AUTHORIZED_USER_IDS` ثم احفظ الملف (`Ctrl+O` ثم `Enter` ثم `Ctrl+X`)، واحمِ صلاحياته:

```bash
chmod 600 .env

# فحص القالب وتشغيل الاختبارات للتأكد من عمل الخطوط والرسوميات بنجاح
npm test
```

### الخطوة 4: تثبيت PM2 وتشغيل البوت في الخلفية

```bash
# تثبيت PM2 عالمياً
sudo npm install -g pm2

# تشغيل البوت عبر ملف الإعداد المجهز
pm2 start ecosystem.config.js

# التحقق من حالة البوت
pm2 status
```

### الخطوة 5: تفعيل التشغيل التلقائي عند إعادة إقلاع الخادم (Auto-Restart on Reboot)

```bash
pm2 startup systemd
```

سيطبع لك الأمر أعلاه سطراً يبدأ بـ `sudo env PATH=...` — انسخه ونفّذه كما هو، ثم احفظ قائمة العمليات الحالية:

```bash
pm2 save
```

بهذا سيعود البوت للعمل تلقائياً فور إعادة تشغيل خادم AWS لأي سبب.

## 6. أوامر PM2 والسجلات والتحديث اليومي

### متابعة السجلات (Logs)

```bash
# عرض السجلات الحية مباشرة من PM2
pm2 logs wasl-bot

# عرض آخر 100 سطر من السجلات
pm2 logs wasl-bot --lines 100

# عرض ملفات السجل المخصصة للتطبيق والأخطاء فقط
tail -f logs/app.log
tail -f logs/error.log
```

### إدارة العملية وإعادة التشغيل

```bash
# عرض حالة البوت واستهلاك الذاكرة والمعالج
pm2 status
pm2 monit

# إعادة تشغيل البوت
pm2 restart wasl-bot

# إيقاف البوت مؤقتاً
pm2 stop wasl-bot
```

### تحديث الكود على الخادم مستقبلاً

```bash
cd ~/wasl-telegram-bot
git pull origin main
npm install --omit=dev
pm2 restart wasl-bot
```

## 7. طريقة استخدام البوت في تيليجرام

1. افتح محادثة البوت واضغط `/start` لإظهار القائمة الرئيسية العربية:
   - **إنشاء إعلان جديد:** يطلب منك إرسال نص الإعلان لتصميمه فوراً.
   - **معاينة القالب:** يرسل لك القالب الرسمي الأصلي بدون أي تعديل.
   - **طريقة الاستخدام:** يعرض خطوات الاستخدام السريعة.
   - **معلومات البوت:** يعرض إعدادات البوت والتاريخ والوقت الحالي بتوقيت الرياض.
2. **الإرسال السريع المباشر:** يمكنك في أي وقت إرسال نص الإعلان مباشرة في المحادثة دون الضغط على أي زر، وسيقوم البوت فوراً بتوليد الصورة وإرسالها لك.
3. بعد استلام الصورة، تظهر لك ثلاثة أزرار تفاعلية أسفلها:
   - **إنشاء إعلان آخر**
   - **إعادة إنشاء الصورة** (يعيد توليد نفس النص بتوقيت اللحظة الحالية المحدّث)
   - **العودة للقائمة الرئيسية**

## 8. استكشاف الأخطاء وإصلاحها (Troubleshooting)

| المشكلة | السبب المحتمل | الحل |
| :--- | :--- | :--- |
| البوت لا يبدأ ويظهر خطأ `Missing required environment variable BOT_TOKEN` | ملف `.env` غير موجود أو الحقل فارغ | تأكد من إنشاء ملف `.env` في جذر المشروع وتعبئة `BOT_TOKEN` و `AUTHORIZED_USER_IDS`. |
| البوت يرد بـ *"هذا البوت مخصص للاستخدام الخاص والمصرح به فقط"* | رقم حسابك غير مضاف في `AUTHORIZED_USER_IDS` | استخرج رقم معرفك عبر `@userinfobot` وأضفه إلى `AUTHORIZED_USER_IDS` في `.env` ثم نفّذ `pm2 restart wasl-bot`. |
| خطأ عند تشغيل Chromium على Ubuntu (`error while loading shared libraries`) | نقص مكتبات النظام الخاصة بـ Chromium | نفّذ الأمر `npx playwright install --with-deps chromium` لتثبيت مكتبات Ubuntu تلقائياً. |
| رسالة *"النص طويل جداً ولا يمكن احتواؤه..."* | النص يحتوي على عدد كبير جداً من الكلمات أو الأسطر يفوق مساحة اللوحة الزجاجية عند أصغر خط مقروء | اختصر النص قليلاً أو قسّمه إلى إعلانين منفصلين للحفاظ على فخامة التصميم وسهولة القراءة. |
| توقف الاستجابة عند تشغيل بوتين بنفس التوكن | تشغيل نسخة محلية على جهازك في نفس وقت عمل نسخة السيرفر عبر Long Polling | أوقف النسخة المحلية (`Ctrl+C`) حتى يستقبل خادم AWS التحديثات بمفرده دون تعارض `409 Conflict`. |
